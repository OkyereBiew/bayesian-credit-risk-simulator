# Bayesian Credit Risk Simulator

A Bayesian machine learning project for probabilistic credit default prediction, uncertainty quantification, and financial risk analysis using Bayesian logistic regression.

## Project Objectives

- Model credit default probabilities
- Quantify uncertainty in financial risk predictions
- Compare probabilistic risk profiles
- Build an interpretable Bayesian risk scoring system

## Technologies

- Python
- PyMC
- pandas
- NumPy
- matplotlib
- scikit-learn
- ArviZ
